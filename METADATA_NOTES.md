# Laboratory metadata and cohort rule documentation

`outputs/lab_variable_metadata.csv` contains one row for each of the 771 released laboratory fields. Exact source labels, including prefixes, are preserved. Released units are standardized dimensionless scores. Counts and quantiles come from `lab_variable_qc.csv`; no patient-level records occur in this file.

The `source_unit_category` column classifies the physical quantity only where the analyte label supports an interpretation. Its adjacent basis column distinguishes this annotation from a verified original hospital unit. Ambiguous assay-specific units remain unknown. A numerical distribution alone cannot uniquely distinguish z-score, percentile, logarithmic, ratio, or other transformations. Consequently the specific family is left unestablished unless evidence supports a narrower interpretation. The two hemoglobin fields have aggregate evidence for a reference-interval-relative interpretation; the specific original transformation family remains unestablished for the other 769 fields. The hemoglobin sign convention is a data-supported inference, not a verified clinical classification. Original hospital units and reference intervals are not present in the extract.

All 408,976,950 cells represent 530,450 laboratory rows multiplied by 771 laboratory columns, including 384,077,273 empty cells. The 24,899,677 nonempty cells are finite numbers. The source-to-release comparison includes empty cells and found no mismatches. These checks establish faithful copying on the standardized scale, not validation of every original clinical concentration.

`outputs/eligibility_rule_dictionary.csv` separates the eight confirmed clinical inclusion categories from the historical text patterns used in descriptive analysis. The original hospital query, exact ICD-10 list, upstream synonyms, field name, diagnostic lookback window and minimum record count were not recovered from the available files. The supplied 939-column extract has no explicit complication or eligibility field. The four released diagnosis sources therefore cannot reproduce upstream eligibility. The dictionary explicitly records these gaps rather than presenting a reconstructed clinical code list as an executed query. Heart failure qualifies independently of cardiomyopathy; at least one of the eight categories is required, with other illnesses permitted.

The companion workbook presents the same laboratory metadata and eligibility dictionary with filters and separate sheets for numerical profiles and explanatory metadata. CSV files remain the machine-readable reference. To rebuild them after regenerating the laboratory profiles, run `python document_metadata.py` from the archive root.

The additional all-field scale assessment is in `outputs/lab_scale_diagnostics.csv` and `outputs/lab_scale_summary.json`. `PROVENANCE.md` and `outputs/source_evidence_inventory.csv` identify the original and downstream materials examined. These checks confirm the release operation for all retained variables without assigning unsupported original transformations.
